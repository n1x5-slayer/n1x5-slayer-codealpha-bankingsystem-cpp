# 💳 CodeAlpha - C++ Banking System

This project is developed as part of the **CodeAlpha Internship Program** under the C++ Development track. It simulates a basic banking system that supports core banking functionalities using C++ object-oriented programming concepts.

## 🔧 Features

- 🔐 **Account Registration & Login**
- 📋 **View Account Details**
- 💰 **Deposit & Withdraw Funds**
- 📈 **Check Balance**
- 🗂️ **Store Data in Text Files**
- 🧠 **Menu-Driven Interface with Validations**

## 📁 File Structure

├── main.cpp # Main program file
├── account.h / .cpp # Account class (optional modularization)
├── README.md # Project documentation
├── accounts.txt # File-based data persistence
